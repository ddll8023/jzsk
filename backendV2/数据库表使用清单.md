# backendV2 数据库表使用清单

## 说明

本文档基于 `backendV2` 当前源码整理，统计范围为：

- MyBatis XML：`src/main/resources/mapper/**/*.xml`
- Java 数据源标注：`@DS`
- 本地 MySQL 数据源配置：`src/main/resources/application-runtime.yml`

本项目本地 MySQL 数据源包括：

| 数据源 | 数据库 | 连接地址 |
| --- | --- | --- |
| `gcdd` | `gcdd` | `localhost:3306/gcdd` |
| `jcxx` | `jcxx` | `localhost:3306/jcxx` |
| `yjxx` | `yjxx` | `localhost:3306/yjxx` |

## 本地 MySQL 已使用表

### `gcdd`

| 表名 | 使用模块 | 主要来源 |
| --- | --- | --- |
| `dict` | 字典管理 | `DictMapper.xml` |
| `dict_detail` | 字典详情 | `DictMapper.xml`、`DictDetailMapper.xml` |
| `duty_log` | 值班日志 | `DutyLogMapper.xml` |
| `duty_schedule` | 值班安排 | `DutyScheduleMapper.xml` |
| `inspection_records` | 巡检记录 | `InspectionRecordsMapper.xml` |
| `maintence_record` | 维修养护记录 | `MaintenanceRecordsMapper.xml` |
| `measuring_item` | 测项管理 | `MeasuringItemMapper.xml` |
| `measuring_station` | 监测站点 | `MeasuringStationMapper.xml` |
| `seepage_data` | 渗流量数据 | `SeepageDataMapper.xml` |
| `warning_facilities` | 预警设施 | `WarningFacilityMapper.xml` |
| `device_fault_record` | 设备故障记录 | `DeviceFaultRecordMapper.xml` |

备注：

- `dict`、`dict_detail` 当前代码未显式标注 `@DS`，按 dynamic-datasource 配置会走主库 `gcdd`。

## 未使用表说明

除上方清单外，本地 MySQL 的其他表在 `backendV2` 当前源码中未发现直接引用。

这里的“未使用”仅表示：

- 未在 `backendV2` 的 Mapper XML 中作为 SQL 表名出现；
- 未通过当前代码路径显式访问；
- 不代表旧后端、外部系统、脚本任务或未来代码不会使用这些表。
