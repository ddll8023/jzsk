# 后端 V2 开发迁移指南

## 一、文档概述

本文档用于指导开发人员从现有后端项目（`backend/szy`）迁移至 V2 模块化架构（`backendV2`）。

> **重要提示**：V2 项目需保证接口返回格式与 V1 完全一致，前端 V2 不做任何适配修改。

---

## 三、V2 项目架构

### 3.1 项目目录结构

V2 项目为单体结构，参考 V1 项目目录设计：

```
backendV2/
├── pom.xml
├── src/main/
│   ├── java/com/jzsk/v2/
│   │   ├── common/               # 公共模块
│   │   │   ├── config/         # 配置类
│   │   │   ├── security/       # 安全模块
│   │   │   └── exception/      # 异常处理
│   │   ├── controller/          # 控制器层
│   │   ├── service/             # 服务层（直接实现类，无接口）
│   │   ├── mapper/             # Mapper接口
│   │   ├── pojo/               # 实体类层
│   │   │   ├── entity/         # 实体类
│   │   │   ├── dto/            # DTO类
│   │   │   └── vo/             # VO类
│   │   ├── utils/              # 工具类
│   │   └── jzskApplication.java # 启动类
│   └── resources/
│       ├── application.yml      # 配置文件
│       └── mapper/              # XML映射文件
```

### 3.2 技术栈变更

| 类别 | V1 (原) | V2 (新) |
|------|---------|---------|
| ORM框架 | MyBatis-Plus 3.4.x | MyBatis 2.x |
| 分页 | Page/IPage | PageHelper |
| 主键策略 | @TableId注解 | Mapper XML配置 useGeneratedKeys |
| 自动填充 | MetaObjectHandler | Service层手动设置 |
| 逻辑删除 | @TableLogic | Mapper XML中手动处理 |

### 3.3 各层职责边界

| 层级 | 职责 | 禁止事项 |
|-----|------|---------|
| Controller | 接收请求、参数校验、调用Service、返回响应 | 业务逻辑、数据转换、文件操作 |
| Service | 业务逻辑处理、事务管理、调用Mapper | 直接操作HTTP请求/响应 |
| Mapper | 数据库操作、SQL执行 | 业务逻辑、数据处理 |
| Entity | 数据模型映射 | 业务逻辑、校验规则 |
| DTO | 接口参数封装 | 业务逻辑 |
| VO | 返回数据封装 | 业务逻辑 |

### 2.4 关键代码参考

#### 统一响应格式 (必须保持一致)

**文件位置**: `backend/szy/src/main/java/com/szy/common/lang/Result.java`

```java
@Data
public class Result<T> implements Serializable {
    private Integer code;
    private String message;
    private T data;

    // 成功响应
    public static <T> Result<T> ok()
    public static <T> Result<T> ok(T data)
    public static <T> Result<T> ok(T data, String message)

    // 失败响应
    public static <T> Result<T> fail()
    public static <T> Result<T> fail(String message)
    public static <T> Result<T> fail(ResponseCode responseCode)
}
```

#### Spring Security 配置

**文件位置**: `backend/szy/src/main/java/com/szy/config/SecurityConfig.java`

```java
@Configuration
@EnableGlobalMethodSecurity(prePostEnabled = true)
public class SecurityConfig extends WebSecurityConfigurerAdapter {
    @Override
    protected void configure(HttpSecurity http) throws Exception {
        http.sessionManagement()
            .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            .and()
            .authorizeRequests()
            .antMatchers("/login", "/logout").permitAll()
            .antMatchers("/swagger-ui/**", "/doc.html").permitAll()
            // 其他需要认证的接口
            .anyRequest().authenticated();
    }
}
```

## 六、数据源配置

### 6.1 多数据源配置

V2 项目复用现有 8 个数据源，在 `application.yml` 中配置：

```yaml
# application.yml
spring:
  datasource:
    dynamic:
      primary: gcdd  # 默认数据源
      datasource:
        # MySQL 数据源
        gcdd:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://localhost:3306/gcdd?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
          username: root
          password: your_password

        jcxx:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://localhost:3306/jcxx?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
          username: root
          password: your_password

        yjxx:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://localhost:3306/yjxx?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
          username: root
          password: your_password

        collector:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://localhost:3306/collector?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
          username: root
          password: your_password

        eb_database:
          driver-class-name: com.mysql.cj.jdbc.Driver
          url: jdbc:mysql://localhost:3306/eb_database?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
          username: root
          password: your_password

        # SQL Server 数据源
        dbo:
          driver-class-name: com.microsoft.sqlserver.jdbc.SQLServerDriver
          url: jdbc:sqlserver://localhost:1433;databaseName=dbo
          username: sa
          password: your_password

        zkxt:
          driver-class-name: com.microsoft.sqlserver.jdbc.SQLServerDriver
          url: jdbc:sqlserver://localhost:1433;databaseName=zkxt
          username: sa
          password: your_password

        # PostgreSQL 数据源
        pgsql:
          driver-class-name: org.postgresql.Driver
          url: jdbc:postgresql://localhost:5432/pgsql
          username: postgres
          password: your_password
```

### 5.2 数据源切换注解

```java
// 使用默认数据源（gcdd）
@Service
public class DefaultService { }

// 切换到指定数据源
@Service
@DS("jcxx")
public class UserService { }

@Service
@DS("collector")
public class RainfallService { }

@Service
@DS("pgsql")
public class SeepageService { }
```
