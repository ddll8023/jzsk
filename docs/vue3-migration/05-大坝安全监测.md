# 大坝安全监测模块迁移文档

## 1. 模块概述
大坝安全监测数据展示与分析模块，包括渗流压力、渗流量、水平/垂直位移、地表位移等监测。

## 2. 组件清单

| 组件 | 路径 | 功能 |
|------|------|------|
| Seepage.vue | views/dam/Seepage.vue | 渗流压力监测分析 |
| Seepagewater.vue | views/dam/Seepagewater.vue | 渗流水位趋势 |
| SeepageFlowMonitor.vue | views/dam/SeepageFlowMonitor.vue | 渗流量监测分析 |
| Sllbaobiao.vue | views/dam/Sllbaobiao.vue | 渗流量报表 |
| Horizontal.vue | views/dam/Horizontal.vue | 水平位移查看 |
| Vertical.vue | views/dam/Vertical.vue | 垂直位移查看 |
| Bxbaobiao.vue | views/dam/Bxbaobiao.vue | 变形报表 |
| jcsj.vue | views/dam/jcsj.vue | 地表位移（监测数据） |
| dstoken.vue | views/dam/dstoken.vue | 外部系统Token获取 |

## 3. 后端API接口

### 渗流监测
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /data-new/points | GET | 获取监测点列表 | - |
| /data-new/page | GET | 渗流数据分页 | pointId, pointIds, startTime, endTime, current, size |
| /data-new/latest-water-elevation | GET | 最新水位高程 | - |
| /seepage-data | GET | 渗流数据 | - |
| /seepage-water-level | GET | 渗流水位 | - |

### 位移监测
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /horizontal-displacement | GET | 水平位移数据 | - |
| /vertical-displacement | GET | 垂直位移数据 | - |
| /external-data/displacement-history | GET | 位移历史数据 | startTime, endTime, size |

### 河道水位
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /st-rivers-r/page | GET | 水位分页 | page, size |
| /st-rivers-r/list | GET | 水位列表 | - |

### 外部系统
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| http://111.4.68.108:30080/api/manager/login | POST | 外部系统登录 | username, password |

## 4. 数据结构

### 渗流数据 (data-new)
```javascript
{
  pointId: string,       // 测点ID
  pointName: string,     // 测点名称
  waterElevation: number,// 水位高程
  collectTime: string,   // 采集时间
  temperature: number    // 温度
}
```

### 位移数据
```javascript
{
  damName: string,       // 大坝名称
  stationId: string,     // 站点ID
  displacement: number,  // 位移值
  measureTime: string    // 测量时间
}
```

- 配置：dataZoom（缩放）、tooltip、legend

## 8. Vue3迁移注意点

1. **ECharts实例管理**：
   - 使用`shallowRef`存储实例
   - `onMounted`初始化
   - `onBeforeUnmount`销毁
   - 窗口resize监听清理

2. **异步数据加载**：
   - `Promise.all`并行请求保持
   - 错误处理逻辑不变

3. **计算属性**：
   - 数据过滤、格式化逻辑迁移到`computed()`

4. **外部系统集成**：
   - dstoken.vue中的外部API调用需验证CORS

5. **响应式数据**：
   - 大数据量表格数据考虑使用`shallowRef`
