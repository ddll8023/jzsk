## 2. 关键依赖分析

### 2.1 大屏模块 (BigScreen.vue) 依赖

| 依赖项 | 类型 | 说明 |
|--------|------|------|
| WaterLevelBar.vue | 子组件 | 水位柱状图 |
| PieChartPanel.vue | 子组件 | 饼图面板 |
| LineChartPanel.vue | 子组件 | 折线图面板 |
| GaugePanel.vue | 子组件 | 仪表盘 |
| ListPanel.vue | 子组件 | 列表面板 |
| WaterLevelRainLine.vue | 子组件 | 水位雨量过程线 |

### 2.2 预警管理模块依赖

| 依赖项 | 类型 | 说明 |
|--------|------|------|
| /dict/kinds | API | 字典数据（预警状态/等级/类型/地点） |
| /warning-indicator-setting/types | API | 监测项类型 |

**结论：预警管理依赖字典服务（系统管理模块提供）**

### 2.3 视频监控模块依赖

| 依赖项 | 类型 | 说明 |
|--------|------|------|
| /dict/kinds | API | 字典数据（摄像头类型/地点/监测点） |
| 海康SDK | 外部 | webVideoCtrl |

**结论：视频监控依赖字典服务和海康SDK**

## 3. 推荐迁移顺序

### 第一批：基础设施（必须最先完成）
```
优先级: ★★★★★ (最高)
预计工时: 3-4天

1. package.json        → 升级所有依赖到Vue3兼容版本
2. vite.config.js      → 配置@vitejs/plugin-vue
3. tailwind.config.js  → 新建 Tailwind CSS 配置
4. postcss.config.js   → PostCSS 配置
5. src/utils/request.js → 新建Axios封装（独立于Vue）
6. src/config/api.js   → 无需修改，验证兼容性
7. src/main.js         → createApp改造 + Tailwind 导入
```

## 6. 风险点

1. **Tailwind CSS 学习曲线** - 团队需熟悉 Tailwind 工具类
2. **Element UI 组件替换** - 表单、表格等复杂组件需自定义实现
3. **海康SDK兼容性** - 第8批视频监控需提前验证
4. **ECharts 5.x** - 图表API可能有变化
5. **大量CRUD组件** - 建议先抽取通用组件再批量迁移
