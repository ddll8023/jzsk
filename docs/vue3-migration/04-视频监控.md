# 视频监控模块迁移文档

## 1. 模块概述
视频监控管理模块，集成海康威视SDK，支持实时视频预览、配置管理、水位/流量监测。

## 3. 后端API接口

### 视频配置
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /video-configuration/list | GET | 配置列表 | currentPage, pageSize, type, name |
| /video-configuration/info/{id} | GET | 配置详情 | id |
| /video-configuration/save | POST | 新增配置 | 表单数据 |
| /video-configuration/update | POST | 更新配置 | 表单数据 |
| /video-configuration/delete/{id} | POST | 删除配置 | id |

## 7. Vue3迁移注意点

1. **海康SDK兼容性**：
   - 需验证SDK在Vue3环境下的兼容性
   - 可能需要封装为独立模块
   - 注意DOM操作时机

2. **树形组件**：
   - el-tree API基本兼容
   - 事件名可能变化

3. **表单验证**：
   - `this.$refs.formRef.validate()` → `formRef.value.validate()`

4. **文件上传**：
   - el-upload API变化需关注

5. **生命周期**：
   - SDK初始化放在`onMounted`
   - SDK销毁放在`onBeforeUnmount`
