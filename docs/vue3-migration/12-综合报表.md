# 综合报表模块迁移文档

## 1. 模块概述
综合报表模块，包括防汛值班管理（值班安排、值班日志、防汛设备）和信息共享上报。

## 2. 组件清单

| 组件 | 路径 | 功能 |
|------|------|------|
| DutySchedule.vue | components/ComprehensiveReport/DutySchedule.vue | 值班安排 |
| DutyLog.vue | components/ComprehensiveReport/DutyLog.vue | 值班日志 |
| Equipment.vue | components/ComprehensiveReport/Equipment.vue | 防汛设备管理 |
| InfoReportYJ.vue | components/ComprehensiveReport/InfoReportYJ.vue | 预警信息上报 |
| InfoReportXY.vue | components/ComprehensiveReport/InfoReportXY.vue | 响应信息上报 |
| InfoReportZQ.vue | components/ComprehensiveReport/InfoReportZQ.vue | 灾情信息上报 |

## 3. 后端API接口

### 值班管理
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /duty-schedule/list | GET | 值班安排列表 | currentPage, pageSize, date |
| /duty-schedule/save | POST | 新增值班安排 | 表单数据 |
| /duty-schedule/update | POST | 更新值班安排 | 表单数据 |
| /duty-schedule/delete/{id} | POST | 删除值班安排 | id |
| /duty-log/list | GET | 值班日志列表 | currentPage, pageSize, date |
| /duty-log/save | POST | 新增值班日志 | 表单数据 |
| /duty-log/update | POST | 更新值班日志 | 表单数据 |
| /duty-log/delete/{id} | POST | 删除值班日志 | id |

### 设备管理
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /equipment/list | GET | 设备列表 | currentPage, pageSize |
| /equipment/save | POST | 新增设备 | 表单数据 |
| /equipment/update | POST | 更新设备 | 表单数据 |
| /equipment/delete/{id} | POST | 删除设备 | id |

### 信息上报
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /info-report/warning/list | GET | 预警上报列表 | currentPage, pageSize |
| /info-report/warning/save | POST | 新增预警上报 | 表单数据 |
| /info-report/response/list | GET | 响应上报列表 | currentPage, pageSize |
| /info-report/response/save | POST | 新增响应上报 | 表单数据 |
| /info-report/disaster/list | GET | 灾情上报列表 | currentPage, pageSize |

## 5. Tailwind CSS 实现方案

### Element UI → Tailwind 对照

| Element UI | Tailwind 实现 |
|------------|--------------|
| el-table | `table-auto w-full` + 自定义样式 |
| el-pagination | Flex 布局 + 按钮组 |
| el-dialog | Fixed 定位 + 遮罩层 |
| el-form | `grid gap-4` 或 `flex flex-col gap-4` |
| el-date-picker | 自定义日期选择器 |
| el-calendar | 自定义日历组件（Grid 布局） |

### 日历组件实现要点

```vue
<!-- 值班日历 Grid 布局 -->
<div class="grid grid-cols-7 gap-1">
  <div v-for="day in days" :key="day.date" 
       class="p-2 border rounded hover:bg-gray-50 min-h-[80px]">
    <span class="text-sm text-gray-500">{{ day.date }}</span>
    <div v-if="day.duty" class="mt-1 text-xs bg-blue-100 text-blue-800 rounded px-1">
      {{ day.duty.name }}
    </div>
  </div>
</div>
```
