# 闸门监控管理模块迁移文档

## 1. 模块概述
闸门实时状态监控、控制操作及报表统计模块。

## 2. 组件清单

| 组件 | 路径 | 功能 |
|------|------|------|
| GateStatus.vue | components/menu/GateSurveilance/GateStatus.vue | 闸门实时状态查询 |
| GateControl.vue | components/menu/GateSurveilance/GateControl.vue | 闸门控制 |
| GateReport.vue | components/menu/GateSurveilance/GateReport.vue | 闸门报表 |

## 3. 后端API接口

| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /gate/status | GET | 闸门状态列表 | - |
| /gate/control | POST | 闸门控制操作 | gateId, action |
| /gate/report | GET | 闸门报表数据 | startTime, endTime |
| /gate/history | GET | 闸门历史记录 | gateId, startTime, endTime |

## 4. 组件交互

```
闸门监控管理
├── GateStatus.vue (实时状态)
│   ├── 闸门列表展示
│   ├── 状态指示（开/关/故障）
│   └── 实时数据刷新
├── GateControl.vue (控制)
│   ├── 闸门选择
│   ├── 控制操作（开/关/停）
│   └── 操作确认弹窗
└── GateReport.vue (报表)
    ├── 时间范围选择
    ├── 数据表格
    └── 导出功能
```

## 5. Tailwind CSS 实现方案

### Element UI → Tailwind 对照

| Element UI | Tailwind 实现 |
|------------|--------------|
| el-table | `table-auto w-full` + 自定义样式 |
| el-tag | `px-2 py-1 rounded text-sm` + 颜色类 |
| el-button | 自定义 Button 组件 |
| el-dialog | Fixed 定位 + 遮罩层 |
| el-date-picker | 自定义日期选择器 |
| el-message-box | 自定义确认弹窗组件 |

### 状态标签颜色

| 状态 | Tailwind 类名 |
|------|--------------|
| 开启 | `bg-green-100 text-green-800` |
| 关闭 | `bg-gray-100 text-gray-800` |
| 故障 | `bg-red-100 text-red-800` |

## 6. Vue3迁移注意点

1. **定时刷新**：
   - `setInterval`需在`onBeforeUnmount`清理
   - 考虑使用`useIntervalFn`（VueUse）

2. **操作确认**：
   - `this.$confirm` → `ElMessageBox.confirm`

3. **状态管理**：
   - 实时状态可考虑WebSocket（如有）
