# 水雨情管理模块迁移文档

## 1. 模块概述
水库水位、雨量数据查询与统计分析模块。

## 2. 组件清单

**命名规范：所有组件文件名使用 PascalCase**

| 组件 | 当前路径 | 迁移后命名 | 功能 |
|------|----------|-----------|------|
| station.vue | waterinformation/station.vue | Station.vue | 降雨查询 |
| waterstorage.vue | waterinformation/waterstorage.vue | WaterStorage.vue | 水库水位查询 |
| dailyrainfall.vue | waterinformation/dailyrainfall.vue | DailyRainfall.vue | 逐日时段雨量 |
| rainbaobiao.vue | waterinformation/rainbaobiao.vue | RainBaoBiao.vue | 雨情报表 |
| riverstation.vue | waterinformation/riverstation.vue | RiverStation.vue | 河道站水位 |
| annualwaterstation.vue | waterinformation/annualwaterstation.vue | AnnualWaterStation.vue | 单站历年水情 |
| waterreport.vue | waterinformation/waterreport.vue | WaterReport.vue | 水情报表 |
| stpextremumb.vue | waterinformation/stpextremumb.vue | StpExtremumb.vue | 测站极值信息 |

## 3. 后端API接口

| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /st-pptn-hour/list | GET | 小时雨量列表 | - |
| /st-rivers-r/page | GET | 水位分页查询 | page, size |
| /st-rivers-r/list | GET | 水位列表 | - |
| /daily-rainfall | GET | 逐日雨量 | - |
| /daily-rainfall | POST | 新增逐日雨量 | 表单数据 |
| /river-station | GET | 河道站数据 | - |
| /annual-water-situation | GET | 历年水情 | - |
| /annual-water-situation | POST | 新增历年水情 | 表单数据 |
| /st-pextremum-b | GET | 测站极值 | stcd(可选) |
| /st-pextremum-b | POST | 新增极值 | 表单数据 |

## 4. 数据结构

### 小时雨量 (st-pptn-hour)
```javascript
{
  tm: [year, month, day, hour, minute], // 时间数组
  drp: number  // 降雨量(mm)
}
```

### 水位数据 (st-rivers-r)
```javascript
{
  tm: string,      // 时间
  z1: number,      // 水位值
  stcd: string     // 站点代码
}
```

## 7. ECharts使用

- 柱状图：降雨量展示
- 折线图：水位趋势
- 配置项：tooltip、grid、xAxis、yAxis、series

## 8. Vue3迁移注意点

1. **ECharts实例**：
   - `this.$refs.chart` → `ref`获取DOM
   - 实例不放入响应式对象
   - `onBeforeUnmount`中销毁实例

2. **计算属性**：
   - `computed` → `computed()`
   - 过滤和分页逻辑保持

3. **日期处理**：
   - 时间数组解析逻辑不变
   - dayjs库兼容

4. **导出功能**：
   - CSV导出逻辑不变
   - file-saver库兼容
