# 管理信息服务模块迁移文档

## 1. 模块概述
机构和人员信息管理模块。

## 2. 组件清单

| 组件 | 路径 | 功能 |
|------|------|------|
| ManageOrganization.vue | components/menu/ManageInformation/ManageOrganization.vue | 机构信息（可编辑） |
| ManageOrganizationRead.vue | components/menu/ManageInformation/ManageOrganizationRead.vue | 机构信息（只读） |
| ManagePerson.vue | components/menu/ManageInformation/ManagePerson.vue | 人员信息（可编辑） |
| ManagePersonRead.vue | components/menu/ManageInformation/ManagePersonRead.vue | 人员信息（只读） |

## 3. 后端API接口

### 机构信息
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /organization/list | GET | 机构列表 | currentPage, pageSize |
| /organization/info/{id} | GET | 机构详情 | id |
| /organization/save | POST | 新增机构 | 表单数据 |
| /organization/update | POST | 更新机构 | 表单数据 |
| /organization/delete/{id} | POST | 删除机构 | id |

### 人员信息
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /person/list | GET | 人员列表 | currentPage, pageSize, name |
| /person/info/{id} | GET | 人员详情 | id |
| /person/save | POST | 新增人员 | 表单数据 |
| /person/update | POST | 更新人员 | 表单数据 |
| /person/delete/{id} | POST | 删除人员 | id |

## 4. 组件交互

```
管理信息服务
├── ManageOrganization(Read).vue
│   ├── 搜索筛选
│   ├── 数据表格+分页
│   ├── 新增/编辑弹窗
│   ├── 删除确认
│   └── Excel导入
└── ManagePerson(Read).vue
    ├── 姓名搜索
    ├── 数据表格+分页
    ├── 新增/编辑弹窗
    ├── 删除确认
    └── Excel导入
```

## 5. Tailwind CSS 实现方案

### Element UI → Tailwind 对照

| Element UI | Tailwind 实现 |
|------------|--------------|
| el-input | `border rounded-lg px-4 py-2 focus:ring-2` |
| el-table | `table-auto w-full` + 自定义样式 |
| el-pagination | Flex 布局 + 按钮组 |
| el-dialog | Fixed 定位 + 遮罩层 |
| el-form | `grid gap-4` 或 `flex flex-col gap-4` |
| el-upload | 自定义上传组件 |

## 6. Vue3迁移注意点

1. **搜索防抖**：
   - 输入搜索考虑防抖处理
   - 可使用VueUse的`useDebounceFn`

2. **Excel导入**：
   - 文件上传逻辑
   - FormData构建

3. **表单重置**：
   - 弹窗关闭时重置表单
