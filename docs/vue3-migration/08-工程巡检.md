# 工程巡检模块迁移文档

## 1. 模块概述
工程巡检管理模块，包括事件研判、巡检记录、维护记录管理。

## 2. 组件清单

| 组件 | 路径 | 功能 |
|------|------|------|
| EventStudy.vue | components/menu/EngineeringPolling/EventStudy.vue | 事件研判（可编辑） |
| EventStudyRead.vue | components/menu/EngineeringPolling/EventStudyRead.vue | 事件研判（只读） |
| PollingRecord.vue | components/menu/EngineeringPolling/PollingRecord.vue | 巡检记录（可编辑） |
| PollingRecordRead.vue | components/menu/EngineeringPolling/PollingRecordRead.vue | 巡检记录（只读） |
| MaintenceRecord.vue | components/menu/EngineeringPolling/MaintenceRecord.vue | 维护记录（可编辑） |
| MaintenceRecordRead.vue | components/menu/EngineeringPolling/MaintenceRecordRead.vue | 维护记录（只读） |

## 3. 后端API接口

### 事件研判
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /event-study/list | GET | 事件列表 | currentPage, pageSize |
| /event-study/info/{id} | GET | 事件详情 | id |
| /event-study/save | POST | 新增事件 | 表单数据 |
| /event-study/update | POST | 更新事件 | 表单数据 |
| /event-study/delete/{id} | POST | 删除事件 | id |

### 巡检记录
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /polling-record/list | GET | 巡检列表 | currentPage, pageSize |
| /polling-record/info/{id} | GET | 巡检详情 | id |
| /polling-record/save | POST | 新增巡检 | 表单数据 |
| /polling-record/update | POST | 更新巡检 | 表单数据 |
| /polling-record/delete/{id} | POST | 删除巡检 | id |

### 维护记录
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /maintence-record/list | GET | 维护列表 | currentPage, pageSize |
| /maintence-record/info/{id} | GET | 维护详情 | id |
| /maintence-record/save | POST | 新增维护 | 表单数据 |
| /maintence-record/update | POST | 更新维护 | 表单数据 |
| /maintence-record/delete/{id} | POST | 删除维护 | id |

## 4. 组件交互

```
工程巡检
├── EventStudy(Read).vue (事件研判)
│   ├── 数据表格+分页
│   ├── 新增/编辑弹窗
│   └── 删除确认
├── PollingRecord(Read).vue (巡检记录)
│   ├── 数据表格+分页
│   ├── 新增/编辑弹窗
│   └── 删除确认
└── MaintenceRecord(Read).vue (维护记录)
    ├── 数据表格+分页
    ├── 新增/编辑弹窗
    └── 删除确认
```

## 5. Tailwind CSS 实现方案

### Element UI → Tailwind 对照

| Element UI | Tailwind 实现 |
|------------|--------------|
| el-table | `table-auto w-full` + 自定义样式 |
| el-pagination | Flex 布局 + 按钮组 |
| el-dialog | Fixed 定位 + 遮罩层 |
| el-form | `grid gap-4` 或 `flex flex-col gap-4` |
| el-input | `border rounded-lg px-4 py-2 focus:ring-2` |
| el-date-picker | 自定义日期选择器 |
