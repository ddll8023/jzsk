## 5. Tailwind CSS 实现方案

### Element UI → Tailwind 对照

| Element UI | Tailwind 实现 |
|------------|--------------|
| el-table | `table-auto w-full` + 自定义样式 |
| el-tree | 自定义树形组件（递归渲染） |
| el-pagination | Flex 布局 + 按钮组 |
| el-dialog | Fixed 定位 + 遮罩层 |
| el-form | `grid gap-4` 或 `flex flex-col gap-4` |
| el-checkbox | 自定义 Checkbox 组件 |
| el-transfer | 自定义穿梭框组件 |

### 权限树组件实现要点

```vue
<!-- 递归树形组件 -->
<template>
  <ul class="pl-4">
    <li v-for="node in nodes" :key="node.id" class="py-1">
      <label class="flex items-center gap-2">
        <input type="checkbox" v-model="node.checked" class="rounded" />
        <span>{{ node.name }}</span>
      </label>
      <TreeNode v-if="node.children" :nodes="node.children" />
    </li>
  </ul>
</template>
```

## 6. Vue3迁移注意点

1. **树形组件**：
   - el-tree API基本兼容
   - 节点选中、展开逻辑

2. **权限配置**：
   - 复选框树形结构
   - 半选状态处理

3. **用户角色关联**：
   - 穿梭框或多选下拉
   - 数据回显

4. **字典缓存**：
   - 全局字典数据
   - 考虑Pinia存储

5. **菜单权限**：
   - 动态路由生成
   - 权限指令
