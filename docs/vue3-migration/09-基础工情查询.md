# 基础工情查询模块迁移文档

## 1. 模块概述
工程基础信息管理模块，包括监测站点、测项信息、各类工程站点（水库、泵站、水厂等）管理。

## 3. 后端API接口

### 监测站点
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /monitor-site/list | GET | 站点列表 | currentPage, pageSize |
| /monitor-site/info/{id} | GET | 站点详情 | id |
| /monitor-site/save | POST | 新增站点 | 表单数据 |
| /monitor-site/update | POST | 更新站点 | 表单数据 |
| /monitor-site/delete/{id} | POST | 删除站点 | id |

### 测项信息
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /monitor-item/list | GET | 测项列表 | currentPage, pageSize |
| /monitor-item/info/{id} | GET | 测项详情 | id |
| /monitor-item/save | POST | 新增测项 | 表单数据 |
| /monitor-item/update | POST | 更新测项 | 表单数据 |
| /monitor-item/delete/{id} | POST | 删除测项 | id |

### 水库
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /reservoir/list | GET | 水库列表 | currentPage, pageSize |
| /reservoir/info/{id} | GET | 水库详情 | id |
| /reservoir/save | POST | 新增水库 | 表单数据 |
| /reservoir/update | POST | 更新水库 | 表单数据 |
| /reservoir/delete/{id} | POST | 删除水库 | id |

### 预警设施
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /warning-facilities/list | GET | 设施列表 | current, pageSize |
| /warning-facilities/add | POST | 新增设施 | 表单数据 |

### 其他工程站点
接口模式统一：`/{entity}/list`, `/{entity}/info/{id}`, `/{entity}/save`, `/{entity}/update`, `/{entity}/delete/{id}`

实体包括：pump-station, water-works, water-distributor, impoundment, ground-source-water, surface-water-sources, individual-flow-sites, individual-pressure-sites, lines, floating-boat, herb, town

## 5. Tailwind CSS 实现方案

### Element UI → Tailwind 对照

| Element UI | Tailwind 实现 |
|------------|--------------|
| el-table | `table-auto w-full` + 自定义样式 |
| el-pagination | Flex 布局 + 按钮组 |
| el-dialog | Fixed 定位 + 遮罩层 |
| el-form | `grid gap-4` 或 `flex flex-col gap-4` |
| el-input/el-select | 自定义表单组件 |
| el-upload | 自定义上传组件 |
| el-descriptions | `grid grid-cols-2 gap-4` 描述列表 |

### 建议抽取通用 CRUD 组件

由于本模块包含 26+ 个结构相似的工程站点组件，强烈建议：

1. 创建 `components/basic/CrudTable.vue` 通用表格组件
2. 创建 `composables/useCrud.js` 通用 CRUD 逻辑
3. 通过配置文件驱动各站点差异化字段

## 6. Vue3迁移注意点

1. **组件复用**：
   - 26个工程站点组件结构高度相似
   - 建议抽取通用CRUD组件
   - 通过配置驱动差异化

2. **表单验证**：
   - 大量表单验证逻辑
   - 统一迁移模式

3. **文件上传**：
   - Excel导入功能
   - el-upload API变化

4. **分页组件**：
   - 分页逻辑统一封装
