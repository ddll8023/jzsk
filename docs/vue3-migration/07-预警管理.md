# 预警管理模块迁移文档

## 1. 模块概述
预警信息处理与预警指标设定模块，支持预警信息的增删改查及指标配置。

## 2. 组件清单

| 组件 | 路径 | 功能 |
|------|------|------|
| PrewarningInformation.vue | components/menu/PrewarningManage/PrewarningInformation.vue | 预警信息处理（可编辑） |
| PrewarningInformationRead.vue | components/menu/PrewarningManage/PrewarningInformationRead.vue | 预警信息处理（只读） |
| PrewarningIndicatorSetting.vue | components/menu/PrewarningManage/PrewarningIndicatorSetting.vue | 预警指标设定（可编辑） |
| PrewarningIndicatorSettingRead.vue | components/menu/PrewarningManage/PrewarningIndicatorSettingRead.vue | 预警指标设定（只读） |

## 3. 后端API接口

### 预警信息
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /warning-information/list | GET | 预警列表 | currentPage, pageSize, position, status, level, type |
| /warning-information/info/{id} | GET | 预警详情 | id |
| /warning-information/save | POST | 新增预警 | 表单数据 |
| /warning-information/update | POST | 更新预警 | 表单数据 |
| /warning-information/delete/{id} | POST | 删除预警 | id |
| /warning-information/position | GET | 预警地点列表 | position |

### 预警指标
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /warning-indicator-setting/search-list | GET | 指标列表 | monitorWarningType |
| /warning-indicator-setting/search-position | GET | 按位置搜索 | position |
| /warning-indicator-setting/types | GET | 监测项类型列表 | - |
| /warning-indicator-setting/info/{id} | GET | 指标详情 | id |
| /warning-indicator-setting/save | POST | 新增指标 | 表单数据 |
| /warning-indicator-setting/update | POST | 更新指标 | 表单数据 |
| /warning-indicator-setting/delete/{id} | POST | 删除指标 | id |

### 字典接口
| 接口 | 方法 | 功能 | 参数 |
|------|------|------|------|
| /dict/kinds | GET | 字典类型 | name (预警状态/预警等级/预警类型/预警地点/监测项) |

## 4. 数据结构

### 预警信息
```javascript
{
  id: number,
  position: string,      // 预警地点
  status: string,        // 预警状态
  level: string,         // 预警等级
  type: string,          // 预警类型
  content: string,       // 预警内容
  createTime: string,    // 创建时间
  updateTime: string     // 更新时间
}
```

### 预警指标
```javascript
{
  id: number,
  monitorWarningType: string,  // 监测项类型
  position: string,            // 位置
  warningValue: number,        // 预警值
  alarmValue: number,          // 报警值
  unit: string                 // 单位
}
```

## 7. Vue3迁移注意点

1. **表单验证**：
   - `this.$refs.formRef.validate()` → `formRef.value.validate()`
   - 验证规则定义方式不变

2. **弹窗关闭回调**：
   - `@close` 事件处理保持
   - 表单重置逻辑不变

3. **文件上传**：
   - el-upload的`action`属性
   - 手动上传逻辑（`http-request`）

4. **消息提示**：
   - `this.$message` → `ElMessage`
   - `this.$confirm` → `ElMessageBox.confirm`

5. **字典数据缓存**：
   - 考虑使用Pinia存储公共字典数据
