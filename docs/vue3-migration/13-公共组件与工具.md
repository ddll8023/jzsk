## 7. Vue3迁移注意点

### Home.vue
1. **菜单组件**：
   - 使用 Tailwind Flex 布局重写侧边栏
   - 菜单项使用 `router-link` + 动态类名
   - 折叠状态使用 `w-16` / `w-64` 切换

2. **keep-alive**：
   - Vue3中使用 `<router-view v-slot>` 包裹

3. **生命周期**：
   - `created` → `setup` 或 `onMounted`

4. **响应式**：
   - `data()` → `ref/reactive`

### Login.vue
1. **表单验证**：
   - 自定义验证逻辑或使用 VeeValidate
   - `formRef.value.validate()` 方式调用

2. **路由跳转**：
   - `useRouter().push()`

3. **消息提示**：
   - 自定义 Toast 组件（Tailwind 实现）

### 工具函数
1. **无需修改**：纯JS模块，Vue3兼容
2. **建议封装为 Composables**

## 8. 基础组件规范

### 8.1 基础组件定义

基础组件特征：
- 无业务属性，仅处理展示和交互
- 高度复用，可在多个业务模块中使用
- 接口稳定，Props 和事件保持向后兼容
- 职责单一，每个组件只做好一件事

### 8.2 Props 定义规范

```vue
<script setup>
const props = defineProps({
  // 必填属性
  title: {
    type: String,
    required: true
  },
  // 可选属性，提供默认值
  size: {
    type: String,
    default: 'md',
    validator: (value) => ['sm', 'md', 'lg'].includes(value)
  },
  // 复杂对象类型
  config: {
    type: Object,
    default: () => ({ showIcon: true })
  }
})
</script>
```

### 8.3 Emits 定义规范

```vue
<script setup>
const emit = defineEmits(['update:modelValue', 'change', 'submit'])

const handleClick = () => {
  emit('change', newValue)
}
</script>
```

## 9. 业务组件规范

### 9.1 业务组件定义

业务组件特征：
- 包含特定业务逻辑和数据处理
- 针对特定业务场景定制
- 由基础组件或其他业务组件组合而成

### 9.2 数据流原则

- Props 传入数据，Emits 发出事件
- 内部状态与外部状态分离
- 避免直接修改 props
