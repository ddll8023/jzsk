## 3. 核心迁移点

### 3.1 Vue3 语法变更
- Options API → Composition API（可选，建议新组件使用）
- `this.$http` → 独立axios实例
- `this.$refs` 访问方式变更
- `v-model` 语法变更
- 事件API移除（`$on`, `$off`, `$once`）
- 过滤器移除 → 计算属性/方法替代

### 3.2 Vue Router 4.x 变更
- `new Router()` → `createRouter()`
- `mode: 'history'` → `history: createWebHistory()`
- 路由守卫参数变更
- `<router-view>` 插槽语法

### 3.3 样式方案迁移（Element UI → Tailwind CSS）

**Tailwind CSS 配置：**
- 安装：`npm install -D tailwindcss postcss autoprefixer`
- 配置文件：`tailwind.config.js`
- 主题定制：通过 `theme.extend` 扩展颜色、间距等

**组件样式迁移策略：**
- 表单组件：使用 Tailwind 工具类重写
- 表格组件：自定义 Tailwind 表格样式
- 弹窗组件：Headless UI 或自定义实现
- 布局组件：Flex/Grid 布局类

**图标迁移：**
- Element UI Icons → FontAwesome
- 使用方式：`<i class="fa fa-xxx"></i>`

### 3.4 第三方库兼容
- ECharts 5.x：API基本兼容
- 海康视频SDK：需验证兼容性
- Leaflet/OpenLayers：需验证兼容性
