# 核心架构迁移文档

## 1. 入口文件 (main.js)

### 当前实现
**文件：** `src/main.js`

**功能：**
- Vue实例创建与挂载
- 全局插件注册（ElementUI、Router）
- Axios配置（baseURL、拦截器）
- 智能API地址选择
- 全局组件注册（downloadExcel）
- 全局样式导入

**全局挂载：**
```javascript
Vue.prototype.$http = axios      // HTTP请求
Vue.prototype.$qs = qs           // 查询字符串
Vue.prototype.$echarts = echarts // 图表
```

### Vue3迁移要点
- `new Vue()` → `createApp()`
- `Vue.use()` → `app.use()`
- `Vue.prototype` → `app.config.globalProperties`
- `Vue.component()` → `app.component()`
- 异步初始化需调整（async bootstrap）

### 2.2 路由守卫

**当前实现：**
```javascript
router.beforeEach((to, from, next) => {
  // 白名单路由直接放行
  if (to.path === '/login' || to.path === '/api-test') return next()
  
  // 检查token
  const tokenstr = window.sessionStorage.getItem('token')
  if (!tokenstr) return next('/login')
  
  next()
})
```

**白名单路由：**
- `/login` - 登录页
- `/api-test` - API测试页

### 2.3 Vue Router 4.x迁移要点

1. **创建方式变更**
   - `new Router()` → `createRouter()`
   - `mode: 'history'` → `history: createWebHistory()`

2. **通配符路由**
   - `path: '*'` → `path: '/:pathMatch(.*)*'`

3. **路由守卫返回值**
   - Vue Router 4.x中`next()`可选
   - 可直接`return false`或`return '/login'`

4. **嵌套路由渲染**
   - `{ render: h => h('router-view') }` → 使用`<RouterView />`组件

5. **懒加载语法**
   - 保持`() => import()`语法，Vue3兼容

## 4. Axios配置

### 当前实现
**位置：** `src/main.js`

### 4.1 默认配置
```javascript
// 请求头配置
axios.defaults.headers.post['Content-Type'] = 'application/x-www-form-urlencoded'

// baseURL动态设置（异步初始化）
const initApiConfig = async () => {
  const apiBaseURL = await getBestApiURL();
  axios.defaults.baseURL = apiBaseURL;
};
```

### 4.2 请求拦截器
```javascript
axios.interceptors.request.use(config => {
  // 请求日志
  console.log('API请求:', (config.method || 'GET').toUpperCase(), config.url);
  console.log('请求头:', config.headers);
  
  // 添加Authorization头（从sessionStorage获取token）
  config.headers.Authorization = window.sessionStorage.getItem('token')
  
  return config
}, error => {
  console.error('请求错误:', error);
  return Promise.reject(error);
})
```

**请求拦截器功能：**
- 自动添加Authorization请求头
- 请求日志输出（URL、方法、请求头）
- 错误捕获与日志

### 4.3 响应拦截器
```javascript
axios.interceptors.response.use(response => {
  // 响应日志
  console.log('API响应:', response.status, response.config.url);
  return response;
}, error => {
  // 错误日志
  console.error('API响应错误:', 
    error.response ? error.response.status : 'unknown', 
    error.response ? error.response.data : 'unknown'
  );
  console.error('错误详情:', error.message);
  return Promise.reject(error);
})
```

**响应拦截器功能：**
- 响应日志输出（状态码、URL）
- 错误状态码捕获
- 错误详情日志

### 4.4 全局挂载
```javascript
Vue.prototype.$http = axios   // HTTP请求实例
Vue.prototype.$qs = qs        // 查询字符串序列化
```

### 4.5 Vue3迁移要点

1. **独立封装建议**
   创建 `src/utils/request.js`：
   ```javascript
   import axios from 'axios'
   import { getBestApiURL } from '@/config/api'
   
   const service = axios.create({
     timeout: 30000,
     headers: {
       'Content-Type': 'application/x-www-form-urlencoded'
     }
   })
   
   // 请求拦截器
   service.interceptors.request.use(
     config => {
       const token = sessionStorage.getItem('token')
       if (token) {
         config.headers.Authorization = token
       }
       return config
     },
     error => Promise.reject(error)
   )
   
   // 响应拦截器
   service.interceptors.response.use(
     response => response,
     error => {
       // 统一错误处理
       // 401: 跳转登录
       // 403: 无权限
       // 500: 服务器错误
       return Promise.reject(error)
     }
   )
   
   export default service
   ```

2. **组件中使用**
   - 方式一：直接导入 `import request from '@/utils/request'`
   - 方式二：全局属性 `app.config.globalProperties.$http = service`
   - 方式三：provide/inject

3. **移除Vue.prototype**
   - `Vue.prototype.$http` → `app.config.globalProperties.$http`
   - 或使用Composition API直接导入

## 7. 代码规范

### 7.1 组件注释规范

每个组件文件顶部必须添加注释：

```vue
<script setup>
/**
 * 组件名称
 * 功能描述：简明扼要说明主要功能
 * 依赖组件：列出依赖的子组件（如有）
 */
</script>
```

### 7.2 导入顺序规范

按以下顺序组织导入语句：

```vue
<script setup>
// 1. Vue 官方 API
import { ref, computed, onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'

// 2. Pinia Store
import { useAuthStore } from '@/stores/auth'

// 3. 工具函数 / 常量
import { formatDate } from '@/utils'
import { PAGE_SIZE } from '@/constants'

// 4. API 接口定义
import { getUserInfo } from '@/api/user'

// 5. 子组件导入
import BaseButton from '@/components/basic/BaseButton.vue'
</script>
```

### 7.3 Props 定义规范

使用对象语法，提供类型、默认值和验证：

```vue
<script setup>
const props = defineProps({
  title: {
    type: String,
    required: true
  },
  size: {
    type: String,
    default: 'md',
    validator: (value) => ['sm', 'md', 'lg'].includes(value)
  },
  config: {
    type: Object,
    default: () => ({ showIcon: true })
  }
})
</script>
```

### 7.4 Emits 定义规范

```vue
<script setup>
const emit = defineEmits(['update:modelValue', 'change', 'submit'])

// 带验证的事件
const emit = defineEmits({
  change: (value) => typeof value === 'string',
  submit: (data) => data !== null
})
</script>
```

### 7.5 命名规范

| 类型 | 命名规则 | 示例 |
|------|----------|------|
| 组件文件 | PascalCase | `UserProfile.vue` |
| 变量 | camelCase | `userName`, `dataList` |
| 常量 | UPPER_SNAKE_CASE | `MAX_PAGE_SIZE` |
| Props | camelCase | `pageTitle` |
| 事件 | kebab-case | `update:modelValue` |
| CSS 类名 | Tailwind 类名 | `flex`, `text-center` |
