## 接口规范

### 通用说明

- **基础路径**: `/api`
- **HTTP方法规范**:
  - `GET`: 查询操作
  - `POST`: 新增、复杂查询、删除
  - `PUT`: 更新操作
  - `DELETE`: 删除操作

### 响应格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {}
}
```

### 分页响应格式

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "records": [],
    "total": 100,
    "current": 1,
    "size": 10,
    "pages": 10
  }
}
```
