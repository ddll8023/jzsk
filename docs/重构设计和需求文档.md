# 后端重构 - 参考文件清单

## 目的

在 `backendV2` 目录下创建全新的后端项目，**完全匹配前端(frontendV2)定义的API接口**，并遵循**规范文档/后端规范文档.md**的要求进行开发。

---

## 重构背景 **现状**：

-前端(frontendV2)已定义好API接口，但后端接口不匹配或未实现
- **目标**：重新编写后端代码，使API接口与前端完全一致
- **产出**：全新的后端项目 `backendV2`

### 7.4 分层架构约束（必须遵循）

| 层级 | 约束 |
|------|------|
| Controller | 只能请求转发，禁止业务逻辑，使用 @RequiredArgsConstructor + private final |
| Service | 接口+实现类，业务逻辑处理 |
| Mapper | **必须使用XML文件，禁止注解SQL** |
| DTO | 请求参数封装，@Schema + 校验注解 |
| VO | 响应数据封装，@Schema 注解 |

### 7.5 HTTP接口规范

- **GET**: 查询操作
- **POST**: 创建、更新、删除、复杂查询
- **禁止**: PUT、DELETE、PATCH
