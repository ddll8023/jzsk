# 后端模块功能设计说明

## 1. 系统架构概述
本项目基于 **Spring Boot** 框架，采用 **MyBatis-Plus** 进行持久层操作，集成 **Redis** 缓存、**Swagger** 文档与 **腾讯云 SMS** 服务。项目结构遵循经典的分层架构：Controller（控制层）、Service（业务层）、Mapper（持久层）、Entity（实体层）。

**根包路径**: `D:\demo\jzsk\backend\szy\src\main\java\com\szy`

## 2. 公共与基础模块 (Infrastructure)

### 2.1 全局配置
负责系统层面的环境与中间件配置。
- **文件路径**: `com.szy.config`
- **主要组件**:
  - `MybatisPlusConfig.java`: 配置分页插件与防全表更新拦截器，保障数据库操作安全。
  - `RedisConfig.java`: 定制 RedisTemplate 序列化方式（String/JSON），支持对象自动缓存。
  - `SwaggerConfig.java`: 配置 API 文档分组与全局参数，自动生成接口调试文档。
  - `WebMvcConfiguration.java`: 配置静态资源映射（图片/视频）、跨域拦截器及 JSON 消息转换器。
  - `CorsConfig.java`: 配置全局 CORS 策略，允许跨域访问的源、头信息及方法。
  - `SchedulingConfig.java`: 配置定时任务支持 (@EnableScheduling)。注意：当前使用默认单线程调度器，所有定时任务串行执行。
  - `SecurityConfig.java`: 基于 Spring Security 的安全配置，实现 JWT 无状态认证过滤器链，定义 URL 白名单（如登录、Swagger）与细粒度权限控制。
  - `AppConfig.java`: 核心 Bean 配置，注册 RestTemplate 用于外部 API 调用，以及 Jackson ObjectMapper 全局配置。
  - `TencentSMSConfig.java`: 集成腾讯云短信 SDK，配置 AppID 与签名，用于发送验证码或报警短信。
  - `UploadConfig.java`: 配置本地文件存储路径映射及上传大小限制。

### 2.2 通用组件
封装系统通用的响应对象、异常处理与工具类。
- **文件路径**: `com.szy.common`
- **主要组件**:
  - `lang/Result.java`: 定义统一 API 响应结构 `Result<T>`，包含状态码、消息与数据载体。
  - `lang/ResponseCode.java`: 定义业务状态码枚举（200成功, 400校验失败, 401未认证等）。
  - `exception/GlobalExceptionHandler.java`: 全局异常处理器，统一处理 `RuntimeException`、参数校验异常等，避免堆栈信息直接暴露。
  - `handler/MyMetaObjectHandler.java`: MyBatis Plus 自动填充策略，自动维护 `create_time` 和 `update_time` 字段。
  - `dto/*`: 数据传输对象，用于接收前端表单数据（如 `PassDto` 密码修改, `DistributorDto` 配水器参数）。
  - `vo/*`: 视图对象，用于向前端展示脱敏或聚合后的数据（如 `DictVO` 字典项, `WaterLevelVO` 水位曲线数据）。

## 3. 业务功能模块详解 (按前端菜单分类)

### 3.1 一张图与可视化 (Map & Visualization)
支撑“一张图”界面的底图要素与实时数据展示，提供高性能数据检索服务。
- **Controller 路径**: `com.szy.controller`
- **详细功能**:
  - **实时监控数据**:
    - `DataNewController.java`: 高性能实时数据接口，利用 Redis 缓存优化，提供水位、流量、工情等全量站点的最新监测值查询，支撑地图点位即时更新。
  - **外部集成**:
    - `ExternalDataController.java`: 用于对接或同步外部系统的实时监测数据，确保地图数据的全面性。
  - **地图资源**:
    - `IconController.java`: 提供 WebGIS 地图所需的设备与站点图标资源。

### 3.2 水雨情管理 (Water & Rain)
对应菜单“水雨情管理”，负责水文监测数据的采集、查询与统计分析。
- **Controller 路径**: `com.szy.controller`
- **详细功能**:
  - **降雨监测** (对应“降雨查询”):
    - `RainfallStationsController.java`: 雨量站档案管理。
    - `DailyRainfallController.java` / `StPptnHourController.java`: 提供小时级降雨明细查询与日/月/年累积降雨量报表统计。
  - **水库与水位** (对应“水库水位查询”):
    - `WaterStorageController.java`: 水库水量数据管理，记录库容变化。
    - `WaterLevelController.java`: 水位历史数据查询、Excel 导入导出及水位统计报表。
    - `WaterLevelCollectorController.java`: 实时水位数据采集接收接口。
  - **流量与河道**:
    - `FlowController.java`: 流量监测数据管理及统计分析。
    - `FlowCollectorController.java`: 流量计数据采集接入。
    - `RiverStationController.java`: 河道水文站管理。
    - `RiverCollectorController.java`: 河道数据采集专用接口。
    - `StRiversRController.java`: 国标河道水情表数据查询。
  - **数据同步服务**:
    - `DataSyncTask.java`: 执行每5分钟一次的数据同步任务，调用 `waterQualityService.syncQualityData()` 同步水质数据，调用 `riverCollectorService.syncFlowData()` 同步流量与水位数据。
  - **统计报表**:
    - `StPextremumBController.java`: 雨量极值统计（最大/最小降雨量）。
    - `AnnualWaterSituationController.java`: 年度水情分析报表。
  - **水质监测** (对应“水质查询”):
    - `WaterQualityController.java`:
      - 实时水质数据列表与最新数据查询。
      - 水质数据统计分析（按时间段/站点）。
      - Excel 数据导入与导出。
    - `WaterQualityCollectorController.java`: 水质自动监测站数据接收与解析接口。

### 3.3 视频监测 (Video)
对应菜单“视频监测”，负责视频流媒体的接入与管理。
- **Controller 路径**: `com.szy.controller`
- **详细功能**:

### 3.4 大坝安全监测 (Dam Safety)
对应菜单“大坝安全监测”，关注工程结构安全指标。
- **Controller 路径**: `com.szy.controller`
- **详细功能**:
  - **渗流监测** (对应“渗流压力/渗流量”):
    - `SeepageDataController.java`: 量水堰渗流量数据采集与查询。

### 3.5 闸门监控管理 (Gate & Control)
对应菜单“闸门监控管理”，实现对水利设施的远程控制与工情监视。
- **Controller 路径**: `com.szy.controller`

    - `GateAlertController.java`: 记录电机过载、限位异常等报警。
    - `DgqController.java` (专项): 电机电气安全监测（三相电流/电压）。
  - **控制与调度**:
    - `GateControlController.java`: 远程启闭指令下发与记录。
    - `WaterDistributorController.java`: 配水调度管理，记录配水计划与执行量。
    - `ImpoundmentController.java`: 蓄水期管理与调度。
  - **报表与档案** (对应“闸门报表”):
    - `GateInfoController.java`: 闸门基础参数档案。
    - `GateOperationController.java`: 启闭操作审计日志。
    - `GateReportController.java`: 闸门运行统计报表。

### 3.6 预警管理 (Warning)
对应菜单“预警管理”，负责系统自动预警与人工事件处理。
- **Controller 路径**: `com.szy.controller`
- **核心组件**: `WarningAutoCheckTask` (定时扫描引擎)
  - **执行频率**: 每5分钟执行一次 (`cron = "0 */5 * * * ?"`).
  - **扫描逻辑**:
    1. **坝前水雨情**: 检查特定站点（4211820043）的水位与雨量，对比四级阈值。
    2. **GNSS位移**: 调用外部接口获取8个基站的位移数据（X/Y/Z/水平），对比阈值。
    3. **MCU模数**: 扫描 `data_new` 表，解析 MCU 测试站的模数数据并进行阈值判定。
- **详细功能**:
  - **预警处理** (对应“预警信息处理”):
    - `WarningInformationController.java`: 预警记录的查询、状态更新（解除/处置）及统计分析。
    - `EventsController.java`: 突发事件的全流程闭环记录（发现-处置-归档）。
  - **指标配置** (对应“预警指标设定”):
    - `WarningIndicatorSettingController.java`: 配置各监测点位的四级报警阈值。
