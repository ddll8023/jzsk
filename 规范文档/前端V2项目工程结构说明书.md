## 1. 项目整体结构可视化 (Tree View)

本项目采用 **Vue 3 (Composition API)** + **Vite** 的现代化架构，目录结构遵循模块化与关注点分离原则。

```
frontendV2/
├── public/                      # [静态资源] 不经过构建处理的公共资源
│   ├── app/                     # 移动端APP安装包存放位置
│   ├── icons/                   # 地图/系统图标资源
│   └── js/                      # 第三方非NPM库 (如WebVideoCtrl海康插件)
├── src/                         # [源代码] 核心开发目录
│   ├── api/                     # [接口层] 后端API请求定义
│   ├── assets/                  # [资源层] 需构建处理的静态资源 (Less/Img)
│   ├── components/              # [组件层] 通用Vue组件
│   │   ├── basic/               # 基础UI原子组件 (按钮、输入框等)
│   │   └── business/            # 业务逻辑组件 (特定业务场景复用)
│   ├── composables/             # [逻辑层] 组合式API (Hooks) 业务逻辑复用
│   ├── config/                  # [配置层] 全局静态配置
│   ├── data/                    # [数据层] 静态常量或模拟数据
│   ├── router/                  # [路由层] 页面路由定义与权限守卫
│   ├── stores/                  # [状态层] Pinia全局状态管理
│   ├── utils/                   # [工具层] 通用辅助函数集
│   ├── views/                   # [视图层] 页面级组件
│   │   ├── basic-info/          # 基础信息管理模块
│   │   ├── dam/                 # 大坝安全监测模块
│   │   ├── engineering/         # 工程管理模块
│   │   ├── gate/                # 闸门控制与监测模块
│   │   ├── hydrology/           # 水文监测模块
│   │   ├── inspection/          # 巡检业务模块
│   │   ├── report/              # 报表统计模块
│   │   ├── system/              # 系统管理 (用户/角色/菜单)
│   │   ├── video/               # 视频监控模块
│   │   ├── warning/             # 预警管理模块
│   │   ├── Home.vue             # 核心布局容器
│   │   ├── Login.vue            # 登录页
│   │   └── OneMap.vue           # "一张图" GIS驾驶舱
│   ├── App.vue                  # 应用根组件
│   └── main.js                  # 应用入口文件 (初始化插件、挂载应用)
├── index.html                   # 应用入口HTML模板
├── package.json                 # 项目依赖说明与脚本配置
├── vite.config.js               # Vite 构建工具配置
├── tailwind.config.js           # TailwindCSS 样式框架配置
└── postcss.config.js            # PostCSS 样式处理配置
```

## 2. 核心目录与功能映射说明

下表详细说明了关键目录及其内部文件的架构职责：

| 目录/文件路径 | 功能模块 | 详细架构职责描述 |
| :--- | :--- | :--- |
| **src/api/** | 接口服务层 | 封装 Axios 请求，按业务领域划分文件。<br>- `auth.js`: 登录认证相关接口<br>- `dam.js/gate.js`: 水利设施业务接口<br>- `video.js`: 监控设备流媒体接口 |
| **src/composables/** | 逻辑复用层 (Hooks) | **Vue3 核心架构特性**。封装可复用的业务逻辑状态与方法。<br>- `useAuth.js`: 用户登录状态、权限校验逻辑<br>- `useMap.js`: GIS地图初始化、图层管理逻辑<br>- `useToast.js`: 全局消息通知逻辑封装<br>- `useSocket.js`: WebSocket实时通信逻辑 |
| **src/stores/** | 状态管理层 | 基于 **Pinia** 的全局状态存储。<br>- `auth.js`: 存储 Token、用户信息、权限列表<br>- `dict.js`: 存储系统字典数据，减少重复请求 |
| **src/utils/** | 工具库 | 纯函数工具集。<br>- `request.js`: **核心**。Axios 实例封装，包含请求/响应拦截器、全局错误处理、Token 注入。<br>- `datetime.js`: 日期时间格式化工具 |
| **src/views/OneMap.vue** | GIS 驾驶舱 | 系统核心视图。集成 Leaflet/OpenLayers 地图引擎，展示水利站点分布、实时数据图层，是系统的主要交互界面。 |
| **public/js/** | 遗留/外部库 | 存放无法通过 NPM 安装的第三方库。<br>- `webVideoCtrl.js`: 海康威视 Web 视频插件，用于视频监控模块的底层推流播放。 |
| **vite.config.js** | 构建配置 | 定义项目构建行为。<br>- 配置 `@` 路径别名<br>- 配置 API 代理 (Proxy) 解决跨域问题<br>- 配置打包分块策略 |

## 3. 架构逻辑与数据流向说明

本项目采用典型的 **MVVM** 架构，并结合 Vue 3 的 Composition API 增强了逻辑复用性。

### 3.1 核心数据流转 (Data Flow)
1.  **视图层 (View)**: 用户在 `views/` 下的页面（如 `Login.vue`）触发操作。
2.  **逻辑层 (Composable)**: 视图调用 `composables/` 下的 Hook（如 `useAuth`）。Hook 内部处理具体的业务逻辑，不直接操作 DOM。
3.  **状态/接口层 (Store/API)**:
    *   如果涉及全局状态变更，Hook 调用 `stores/auth.js` 修改 Pinia 状态。
    *   如果涉及服务器数据，Hook 调用 `api/auth.js` 发起网络请求。
4.  **基础设施层 (Utils)**: `api` 层通过 `utils/request.js` 发送 HTTP 请求，经由拦截器处理认证头 (Bearer Token) 和统一错误响应。

### 3.2 模块化设计思路
*   **业务逻辑抽离**: 页面组件 (`.vue`) 仅负责 UI 展示和事件绑定，复杂的业务逻辑（如地图打点、表单校验、分页查询）被抽离到 `composables` 目录中。这使得逻辑代码可以脱离 UI 独立测试和复用。
*   **GIS 独立封装**: 地图相关功能极其复杂，项目中通过 `useMap`、`useMapLayers` 等 Hook 将地图操作封装，避免地图逻辑侵入业务组件。
*   **按需加载**: 路由配置 (`router/index.js`) 中采用了动态导入 (`import()`)，结合 Vite 的分包策略，实现了路由级的代码分割，提升首屏加载速度。

## 4. 开发规范摘要

*   **文件命名**: 组件文件使用大驼峰 (`MyComponent.vue`)，JS 工具文件使用小驼峰 (`myUtils.js`)。
*   **样式管理**: 优先使用 TailwindCSS 原子类，复杂样式使用 Less/Sass 编写，并限定 `<style scoped>` 作用域。
*   **路径引用**: 统一使用 `@/` 别名指向 `src/` 目录，避免使用相对路径 `../../`。
