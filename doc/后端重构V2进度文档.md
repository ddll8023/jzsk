# 后端重构V2进度文档

## 1. 文档说明

本文档用于记录 V2 重构的进度信息，重点跟踪以下内容：

1. 当前所处阶段
2. 已完成内容
3. 后续阶段拆分
4. 阶段依赖关系
5. 当前待办事项

当前时间：`2026-03-23`

## 2. 拆分原则

为保证后续开发颗粒度可控，进度文档按以下口径维护：

1. A-C 属于准备、骨架、契约冻结阶段，按单一治理产出拆分。
2. D-G 属于实现阶段，默认采用“一个小阶段 = 一个接口”或“一个小阶段 = 一个任务方法”。
3. “一个接口”按“请求方法 + 路径”判定，例如 `GET /api/users/page` 与 `POST /api/users/create` 必须拆成两个独立阶段项。
4. 前端若复用同一路径承载普通查询和搜索，只记为一个接口阶段，不重复计数。
5. 模块、页面、Controller、Service 只作为分组视图，不再直接作为进度项。
6. H 阶段属于联调与切换里程碑，保留批次级跟踪，但不替代 D-G 的接口级拆分。

## 3. 当前阶段

当前已完成 A、B、C 三个治理阶段全部阶段项，并完成 D 阶段中的 D1 认证接口组、D2 字典主表接口组、D3 字典详情接口组、D4 用户接口组、D5 角色接口组、D6 部门接口组、D7 组织接口组、D8 人员接口组，共完成 `45` 个接口级阶段项（其中 D1-02 已废弃）；E 阶段预警与任务核心阶段尚未开始。

`backendV2` 当前已具备独立工程、公共基础层、鉴权入口、调度基础框架以及字典、用户、角色、部门、组织相关能力；后续开发应直接按 D8-01 开始推进，避免再次以”部门/组织/人员模块整体”作为开发单位。

## 4. 已确认前提

| 项目 | 已确认内容 |
| --- | --- |
| 重构方式 | 在新建 `V2` 目录中重做，不直接在旧目录上修改 |
| 接口规范 | V2 只使用 `GET` 和 `POST` |
| 前端协同 | 当前若存在 `PUT`、`DELETE`，前端也需要同步调整 |
| 逻辑来源 | 旧后端逻辑必须作为实现参考来源，允许在分层和流程上优化 |
| 数据库边界 | 必须完全复用旧项目既有数据库、表结构、字段语义和数据来源，不为 V2 另建平行业务库表模型 |
| 重构范围 | 不只包含接口，也包含定时任务、数据同步、自动预警等内容 |

## 8. 阶段依赖关系

### 8.1 主链路

`A -> B -> C -> D -> E/F/G -> H`

### 8.2 关键依赖

| 阶段 | 依赖说明 |
| --- | --- |
| B | 依赖 A 完成规则和范围冻结 |
| C | 依赖 B 的公共基础能力 |
| D | 依赖 C 的契约和 DTO/VO 范围冻结 |
| E | 依赖 D 的系统基础能力，自动预警任务还依赖 G 阶段的监测查询能力 |
| F | 依赖 D 的系统基础能力，监测站点/监测项作为工程数据底座 |
| G | 依赖 D 的系统基础能力，部分任务迁移依赖查询接口先落地 |
| H | 依赖 D/E/F/G 的核心能力完成 |

### 8.3 接口级通用依赖规则

1. 同一资源默认按 `page/list -> detail -> create -> update/delete -> assign/options/export/upload` 顺序推进。
2. 引用型接口必须先完成被引用资源的基础查询接口，例如 `GET /api/roles/options` 先于 `POST /api/users/roles/assign`。
3. 任务迁移必须晚于其直接依赖的数据查询接口和业务落库接口。

### 9.2 V2 接口规范冻结结果

| 维度 | 冻结结果 |
| --- | --- |
| 统一前缀 | 全部 V2 接口使用 `/api` |
| 资源命名 | 小写英文复数 + `kebab-case` |
| 分页查询 | `GET /api/{resources}/page` |
| 普通列表 | `GET /api/{resources}/list` |
| 详情查询 | `GET /api/{resources}/{id}` |
| 新增/修改/删除 | `POST /create`、`POST /update`、`POST /delete` |
| 批量动作 | `POST /batch-delete` 等动作型路径 |
| 选项接口 | `GET /options`、`GET /options/tree`、`GET /options/list` |
| 导出与上传 | `GET /export`、`POST /upload` |
| 分页参数 | 统一为 `page`、`size` |
| 分页返回 | 统一为 `list/total/page/size/totalPages` |

### 9.3 DTO/VO 范围冻结结果

| 范围 | 冻结结果 |
| --- | --- |
