## 技术栈

- 后端语言与运行环境：Java 8；`backendV2/pom.xml` 中配置 `java.version` 为 `1.8`，用于后端服务开发与运行。
- 后端框架：Spring Boot 2.6.2；通过 `spring-boot-starter-parent`、`@SpringBootApplication` 和 Web/Security/Validation/Actuator Starter 构建 REST 后端、认证授权、参数校验和健康检查能力。
- Web 接口层：Spring MVC；Controller 中使用 `@RestController`、`@GetMapping`、`@PostMapping` 暴露 HTTP 接口。
- 安全认证：Spring Security + JWT；`SecurityConfig` 配置无状态认证链，`JwtTokenService` 使用 `io.jsonwebtoken:jjwt` 生成和解析 Bearer Token。
- 数据访问：MyBatis；`mybatis-spring-boot-starter`、`@MapperScan` 与 `resources/mapper/**/*.xml` 共同完成 Mapper 接口和 XML SQL 映射。
- 多数据源：dynamic-datasource-spring-boot-starter；`application-runtime.yml` 中配置多个动态数据源，覆盖 MySQL、SQL Server、PostgreSQL 等业务库。
- 数据库：MySQL、SQL Server、PostgreSQL；`pom.xml` 引入对应 JDBC 驱动，运行时配置中分别用于工程调度、基础信息、预警信息、采集库、GNSS/监测库等数据访问。
- 向量数据库：未发现向量数据库依赖或配置；项目中未检索到 Milvus、Chroma、FAISS、pgvector 等相关调用。
- 大模型 / LLM 调用：未发现大模型调用依赖或配置；项目中未检索到 OpenAI、LangChain、Ollama、通义千问等 SDK 或 HTTP 调用封装。
- 接口文档：springdoc-openapi-ui；`OpenApiConfig` 与 `pom.xml` 依赖用于生成 Swagger/OpenAPI 文档入口。
- 参数校验：Spring Validation；DTO 中配合校验注解承载接口入参约束。
- 对象与样板代码：Lombok；实体、DTO、VO、Service 等类中使用 Lombok 简化 getter/setter、构造器与日志代码。
- JSON 处理：Jackson；`JacksonConfig` 与 Spring Boot Jackson 配置用于日期时间序列化和 JSON 格式控制。
- 文件存储：阿里云 OSS；`aliyun-sdk-oss`、`AliOSSProperties`、`AliOSSUtils` 用于对象存储上传和资源访问。
- Excel 处理：EasyExcel；`easyexcel` 与 `ExcelUtils`、Excel VO 用于表格导出。
- 定时任务：Spring Scheduling；`SchedulerConfig`、`task` 包及预警检查任务用于水雨情、GNSS、MCU 等自动检查。
- 日志与链路标识：SLF4J/Logback + 自定义 Filter；`TraceIdFilter`、`RequestLoggingFilter`、`TraceIdUtils` 用于请求日志与 traceId 注入。
- 前端框架：Vue 3；`frontendV2/package.json` 引入 `vue`，入口 `main.js` 使用 `createApp` 挂载应用。
- 前端路由：Vue Router 4；`router/index.js` 使用 `createRouter`、`createWebHistory` 配置页面路由和登录守卫。
- 前端状态管理：Pinia；`main.js` 注册 Pinia，`stores/auth.js`、`stores/dict.js` 管理认证和字典状态。
- 前端构建工具：Vite 5；`vite.config.js` 使用 `@vitejs/plugin-vue`，负责 Vue 单页应用构建、开发代理和路径别名。
- 前端样式：Tailwind CSS + PostCSS + Sass/Less；`tailwind.config.js`、`postcss.config.js` 和样式文件用于原子化样式、CSS 后处理及局部样式扩展。
- HTTP 请求：Axios；`utils/request.js` 封装请求实例、Token 注入、分页数据标准化和 401 跳转处理。
- 地图 GIS：OpenLayers + 天地图 + GeoServer WMS；`useMap.js` 创建天地图底图，`useMapLayers.js` 加载 GeoServer WMS 图层。
- 图表：ECharts；大坝监测、渗流、位移等组件使用 ECharts 绘制趋势图和统计图。
- 视频监控：video.js 与海康 WebVideoCtrl 插件；`package.json` 和 `public/js` 中相关资源用于视频播放和监控画面接入。
- 图标：FontAwesome；`main.js` 引入 `@fortawesome/fontawesome-free/css/all.min.css`，前端页面使用统一图标样式。
- 时间处理：dayjs；前端依赖中用于日期时间格式化。
- 表格导出：xlsx、file-saver、js-export-excel；前端依赖中用于浏览器侧表格/Excel 导出。
- 移动端交付资源：APK 静态包；`frontendV2/public/app/jzsk-inspection.apk` 由前端下载页提供巡检 APP 安装包下载。
